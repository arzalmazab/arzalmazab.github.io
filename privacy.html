Privacy Policy

Last updated: October 21, 2026

ARZ Cloud Hub is a Windows desktop application for managing cloud storage accounts authorized by the user.

Google user data

ARZ Cloud Hub accesses Google Drive data only after the user explicitly authorizes the application through Google OAuth. Access is used to provide functions requested by the user, including browsing files, displaying storage information, uploading, downloading, organizing, and managing content in the user's own Google Drive accounts.

OAuth credentials

OAuth access and refresh tokens used by the desktop application are stored locally on the user's Windows device as part of the application's connection configuration. ARZ Cloud Hub is designed to protect sensitive local secrets using Windows security mechanisms where applicable. The application does not require or store a user's Google account password for Google OAuth access.

Data sharing

ARZ Cloud Hub does not sell Google user data, use it for advertising, or provide it to advertisers. Cloud data is accessed only to perform user-requested cloud-management operations.

Data retention

Connection information and local application data remain on the user's device unless the user removes an account, clears application data, or otherwise deletes the local configuration.

User control

Users may disconnect a Google account from ARZ Cloud Hub at any time and may also revoke the application's Google access from their Google Account security settings.

Contact

For questions about this privacy policy or ARZ Cloud Hub, contact the developer through the support email shown on the application's Google OAuth consent screen.
