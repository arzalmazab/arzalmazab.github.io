About ARZ Cloud Hub

ARZ Cloud Hub is a Windows desktop application that helps users manage their own cloud storage accounts from one interface. It can connect to supported cloud providers, browse files, view storage usage, upload and download files, and manage cloud content.

Google Drive access

Google Drive access is requested only after the user explicitly authorizes ARZ Cloud Hub through Google OAuth. The app uses that authorization to provide cloud-management functions requested by the user, such as browsing files, viewing storage information, uploading, downloading, and organizing content in the user's own Google Drive accounts.
